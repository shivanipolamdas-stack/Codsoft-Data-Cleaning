# CodSoft Data Cleaning & Preprocessing

## Task 1: Data Cleaning

This project performs data cleaning and preprocessing on the Netflix Titles dataset using Python and Pandas.

### Dataset
- Original dataset: `data/netflix_titles.csv`
- Cleaned dataset: `data/cleaned_netflix_titles.csv`

### Cleaning Steps
- Checked dataset structure and information
- Checked missing values
- Checked duplicate records
- Handled missing values
- Checked and corrected data types
- Saved the cleaned dataset

### Tools Used
- Python
- Pandas
- VS Code
- GitHub

### Output
The cleaned dataset is saved as:

`data/cleaned_netflix_titles.csv`
